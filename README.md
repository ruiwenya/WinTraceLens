WinTraceLens 是一款面向 Windows 应急响应的本地化分析工具，提供进程信息、主机持久化、关注项汇总、威胁分析、事件日志、历史通信、文件痕迹、YARA 扫描和 AI 辅助研判等功能。

工具采用 Go 编写，支持 GUI 运行，重点帮助安全人员快速查看进程路径、MD5、签名状态、网络连接、服务、计划任务、启动项、登录事件、PowerShell 事件和可疑内存行为，并将多类证据关联起来，辅助排查挖矿木马、蠕虫、远控木马、异常登录和可疑持久化风险。

工具仅供学习交流，在AI辅助方面选择AI大模型供应商并输入api-key后可持续对话，api-key仅当前进程运行存储，关闭程序则清空记录，后续会支持win7、winserver2012等系统运行。
